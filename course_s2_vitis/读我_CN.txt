Steps to Create a Vivado Project

1. Extract the zip package
2. Open the corresponding project; for example: C:\Users\Administrator\Desktop\vivado_2023.1\AX7010_2023.1\course_s1_fpga\01_led
3. For S1 tutorial, open the auto_create_project folder; for S2 tutorial, open the vivado/auto_create_project folder
4. Open the create_project.bat file with a text editor, modify the D:\Xilinx2023.1\Vivado\2023.1\bin\vivado.bat path to your own 2023.1 version path, save
5. Double-click create_project.bat file, wait for Vivado to create the project
6. Project creation is complete. In the parent directory of the create_project.bat file, you can see the newly generated Vivado project folder
7. Double-click to open the .xpr file in the corresponding project folder
8. Wait for the GUI interface to open

Steps to Create a Vitis Project

1. Extract the zip package
2. Open the corresponding project; for example: C:\Users\Administrator\Desktop\vivado_2023.1\AX7010_2023.1\course_s2_vitis\01_ps_hello
3. Open the S2 tutorial Vitis/auto_create_vitis folder
4. Open the build_vitis.bat file with a text editor, modify the D:\Xilinx2023.1\Vitis\2023.1\bin\xsct.bat path to your own 2023.1 version path, save
5. Double-click the build_vitis.bat file, wait for the Vitis project to be created
6. Project creation is complete. In the parent directory of the build_vitis.bat file, you can see the newly generated Vitis project folder
7. Run the Vitis software, navigate to C:\Users\Administrator\Desktop\vivado_2023.1\AX7010_2023.1\course_s2_vitis\01_ps_hello\Vitis
8. Vitis project creation is complete
