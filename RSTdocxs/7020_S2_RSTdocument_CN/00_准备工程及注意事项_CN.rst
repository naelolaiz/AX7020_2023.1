Notes
-----

Every project directory contains a bootimage folder that stores the corresponding BOOT.bin file. You can copy this file to the Vitis_image_download folder to overwrite the existing BOOT.bin.

.. image:: images/000_media/image2.png
      
The vitis_image_download folder is located under the course_s2_vitis directory. Enter the folder, right-click on program_qspi.bat, and open it for editing.

.. image:: images/000_media/image3.png
      
.. image:: images/000_media/image4.png
      
Change the program_flash path to your own software installation path, then save and close.

.. image:: images/000_media/image5.png
      
Double-click program_qspi.bat to download BOOT.BIN to QSPI FLASH. It is recommended to use JTAG mode for downloading.

.. image:: images/000_media/image6.png
      
Alternatively, you can use the SD card boot method by copying the BOOT.bin file to the SD card for booting.
