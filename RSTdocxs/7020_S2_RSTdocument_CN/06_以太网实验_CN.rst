Ethernet Experiment (LWIP)
==========================

**The Vivado project for this experiment is "net_test".**

The development board has 1 Gigabit Ethernet port connected via the RGMII interface. This experiment demonstrates how to use the built-in LWIP template in Vitis for Gigabit Ethernet TCP communication.

Although LWIP is a lightweight protocol stack, it can be somewhat difficult to use if you have never worked with it before. It is recommended to familiarize yourself with LWIP-related knowledge first.

Vivado Project Setup
--------------------

Save a copy of "ps_hello" as a "net_test" Vivado project. The PS-side Ethernet 0 has already been configured.

Download and Debug
------------------

The test environment requires a router that supports DHCP. The development board can automatically obtain an IP address when connected to the router. The host computer and the development board must be on the same network so they can communicate with each other.

Ethernet Test
~~~~~~~~~~~~~

1) Connect the serial port and open a serial debug terminal, connect the PS-side Ethernet cable to the router, and run Vitis

.. image:: images/06_media/image2.png
      
2) You can see some information printed on the serial port, showing that the automatically obtained address is "192.168.1.63", the connection speed is 1000Mbps, and the TCP port is 7

.. image:: images/06_media/image3.png
      
3) Connect using telnet

.. image:: images/06_media/image4.png
      
4) When a character is entered, the development board returns the same character

Experiment Summary
------------------

Through this experiment, we gained a deeper understanding of Vitis program development. This experiment only briefly explains how to create an LWIP application. LWIP can implement protocols such as UDP and TCP. In subsequent tutorials, we will provide specific Ethernet-based applications, such as sending ADC-acquired data over Ethernet, and sending camera data over Ethernet to be displayed on a host computer.
