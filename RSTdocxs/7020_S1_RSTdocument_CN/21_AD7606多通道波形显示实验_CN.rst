AD7606 Multi-Channel Waveform Display Experiment
==================================================

**The Vivado project for this experiment is "ad7606_hdmi_test".**

This experiment practices using an ADC. The ADC module used in this experiment is the AN706, with a maximum sampling rate of 200KHz and 16-bit precision. The experiment displays 2 channels of AN706 input as waveforms on an HDMI display, allowing us to observe waveforms in a more intuitive way. This serves as a prototype of a digital oscilloscope.

Experiment Principles
---------------------

The AD7606 is an integrated 8-channel simultaneous sampling data acquisition system. It integrates on-chip input amplifiers, overvoltage protection circuits, second-order analog anti-aliasing filters, an analog multiplexer, a 16-bit 200kSPS SAR ADC with a digital filter, a 2.5V reference voltage source, reference voltage buffer, and high-speed serial and parallel interfaces.

The AD7606 operates from a single +5V power supply and can handle ±10V and ±5V true bipolar input signals, while all channels sample at throughput rates up to 200KSPS. The input clamp protection circuit can withstand voltages up to ±16.5V.

Regardless of the sampling frequency, the AD7606 maintains an analog input impedance of 1M ohm. It operates from a single power supply with on-chip filtering and high input impedance, thus eliminating the need for driver op-amps and external bipolar power supplies.

The AD7606 anti-aliasing filter has a 3dB cutoff frequency of 22kHz; at a sampling rate of 200kSPS, it provides 40dB anti-aliasing rejection. The flexible digital filter is pin-driven and can improve the signal-to-noise ratio (SNR) while reducing the 3dB bandwidth.

AD7606 Timing
~~~~~~~~~~~~~

.. image:: images/21_media/image4.png
      
The AD7606 can simultaneously sample all 8 analog input channels. When the two CONVST pins (CONVSTA and CONVSTB) are tied together, all channels are sampled simultaneously. The rising edge of this shared CONVST signal initiates simultaneous sampling of all analog input channels (V1 through V8).

The AD7606 has a built-in on-chip oscillator for conversion. The conversion time for all ADC channels is tCONV. The BUSY signal informs the user that a conversion is in progress. Therefore, when a CONVST rising edge is applied, BUSY goes to logic high,
and goes low at the end of the entire conversion process. The BUSY signal falling edge is used to return all eight sample-and-hold amplifiers to tracking mode. The BUSY falling edge also indicates that data from all 8 channels can now be read from the parallel bus DB[15:0].

AD7606 Configuration
~~~~~~~~~~~~~~~~~~~~~

In the AN706 8-channel AD module hardware circuit design, we configure the operating mode of the AD7606 by setting three configuration pins with pull-up or pull-down resistors.

The AD7606 chip supports either external reference voltage input or internal reference voltage. If using an external reference voltage, the chip's REFIN/REFOUT pin requires an external 2.5V reference source. If using the internal reference voltage, the REFIN/REFOUT pin outputs the 2.5V internal reference voltage. The REF
SELECT pin is used to select between the internal and external reference voltage. In this module, since the internal reference voltage precision of the AD7606 is already very high (2.49V~2.505V), the circuit design uses the internal reference voltage.

+---------------------+---------------+--------------------------------+
| **Pin Name**        | **Level**     | **Description**                |
+=====================+===============+================================+
| REF SELECT          | High          | Use internal 2.5V reference    |
+---------------------+---------------+--------------------------------+

The AD7606 AD conversion data acquisition can use either parallel mode or serial mode. Users can set the communication mode by configuring the PAR/SER/BYTE SEL pin level. In our design, we chose parallel mode to read the AD7606 AD data.

+-----------------------+--------------+-------------------------------+
| **Pin Name**          | **Level**    | **Description**               |
+=======================+==============+===============================+
| PAR/SER/BYTE SEL      | Low          | Select parallel interface     |
+-----------------------+--------------+-------------------------------+

The analog input range of the AD7606 can be set to ±5V or ±10V. When set to ±5V input range, 1LSB=152.58uV; when set to ±10V input range, 1LSB=305.175uV.
Users can set the analog input voltage range by configuring the RANGE pin level. In our design, we chose the ±5V analog voltage input range.

+-----------------------+--------------+-------------------------------+
| **Pin Name**          | **Level**    | **Description**               |
+=======================+==============+===============================+
| RANGE                 | Low          | Analog input range: ±5V       |
+-----------------------+--------------+-------------------------------+

The AD7606 has a built-in optional digital first-order sinc filter, which should be used in applications with lower throughput rates or requiring higher signal-to-noise ratios. The oversampling ratio of the digital filter is controlled by the oversampling pins OS[2:0]. The table below provides the oversampling bit decoding for selecting different oversampling ratios.

.. image:: images/21_media/image5.png
      
In the AN706 module hardware design, OS[2:0] has been routed to the external interface. The FPGA or CPU can control the OS[2:0] pin levels to select whether to use the filter, achieving higher measurement accuracy.

The ad7606_if module is the interface module for the AN706, which completes 8-channel AD data acquisition from the AD706 input. It generates the AD conversion signal ad_convstab according to the AD706 chip timing, waits for the ADC busy signal to become inactive, then generates the chip select signal and sequentially reads the 8-channel AD data.

The ad7606_sample module mainly completes single-channel data conversion for the AD706. First, it converts the input data to unsigned numbers, then takes only the upper 8 bits of data, converting the data width to 8-bit (for compatibility with other 8-bit AD module programs). Additionally, it collects 1280 data samples each time, then waits for a period before continuing to collect the next 1280 data samples.

grid_display Module Ports

The wav_display module mainly completes waveform data overlay display. The module contains a dual-port RAM, where the write port is written by the ADC acquisition module and the read port is used by the display module. When the grid display area is active, each display line reads the AD data values stored in RAM and compares them with the Y coordinate to determine whether to display the waveform or not.
