7-Inch LCD Display Experiment
=============================

**The Vivado project for this experiment is "lcd7_test".**

Based on the HDMI output experiment, this chapter introduces the display on a 7-inch LCD screen.

---------------------

1. LCD Drive Timing

The LCD display starts from the top-left corner of the screen and displays pixel by pixel from left to right. After completing each row, it returns to the beginning of the next row on the left side. During this period, horizontal blanking is required, and at the end of each row, horizontal sync signals are used for synchronization. There are two LCD driving modes: HV mode and DE mode. Both modes can drive the LCD, and data is sampled on the rising edge of DCLK. The following is the horizontal display timing diagram:

.. image:: images/20_media/image3.png
      
The LCD horizontal display timing parameters are shown in the table below:

Program Design
--------------

This experiment is actually quite simple. The main difference from the HDMI display is that the RGB-to-DVI module is not needed, and the output can be directly in RGB format. Below is the file structure with the rgb2dvi module removed.

.. image:: images/20_media/image7.png
      
Since the LCD resolution is 800x480, the macro definitions in video_define.v need to be modified.

.. image:: images/20_media/image8.png
      
The PLL output clock frequency is also changed to 33MHz, which is the pixel clock for 800x480 resolution.

.. image:: images/20_media/image9.png
      
Additionally, ax_pwm is instantiated in top.v to adjust the LCD brightness, set to 200Hz with a 30% duty cycle.

.. image:: images/20_media/image10.png
