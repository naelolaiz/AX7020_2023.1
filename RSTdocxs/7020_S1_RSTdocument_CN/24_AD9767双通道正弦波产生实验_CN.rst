AD9767 Dual-Channel Sine Wave Generation Experiment
=====================================================

**The experiment Vivado project is "ad9767_dual_sin_wave".**

This chapter introduces the experiment of generating two sine waves using the AN9767 module.

Hardware Introduction
---------------------

The dual-channel 14-bit DA output module AN9767 uses the AD9767 chip from ANALOG DEVICES, supporting independent dual-channel, 14-bit, 125MSPS digital-to-analog conversion. The module has a 40-pin female header for connecting to the FPGA development board, and 2 BNC connectors for analog signal output.

AN9767 Module Parameter Description
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The following are the detailed parameters of the AN9767 dual-channel DA module:

-  DA conversion chip: AD9767;

-  Number of channels: 2 channels;

-  DA conversion resolution: 14bit;

-  DA update rate: 125 MSPS;

-  Output voltage range: -5V~+5V;

-  Module PCB layers: 4 layers, with independent power and GND layers;

-  Module interface: 40-pin 2.54mm pitch header, facing downward;

-  Operating temperature: -40°~85°, all chips used in the module meet industrial temperature range

-  Output interface: 2 BNC analog output interfaces (can be directly connected to an oscilloscope using BNC cables);

AD9767 Chip Introduction
~~~~~~~~~~~~~~~~~~~~~~~~~

`AD9767 <http://www.bdtic.com/ADI/AD9767.html>`__\ is a dual-port, high-speed, dual-channel, 14-bit CMOS DAC. The chip integrates two high-quality TxDAC+® cores, a voltage reference, and digital interface circuitry in a 48-pin small LQFP package. The device provides excellent AC and DC performance while supporting update rates up to 125 MSPS. The functional block diagram of `AD9767 <http://www.bdtic.com/ADI/AD9767.html>`__\ is shown below:

.. image:: images/24_media/image4.png
      
Current-to-Voltage Conversion and Amplification
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Both DA outputs of the AD9767 are complementary current outputs IoutA and IoutB. When the AD9767 digital input is at full scale (all 14 bits of DAC input data are high), IoutA outputs a full-scale current of 20mA, and IoutB outputs 0mA. The relationship between the current and DAC data is shown in the following formula:

.. image:: images/24_media/image5.png
      
Where IoutFS=32 x Iref. In the AN9767 module design, the value of Iref is determined by the resistance of R16. If R16=19.2K, then Iref is 0.625mA, making IoutFS equal to 20mA.

The current output from AD9767 is converted to a voltage range of -1V~+1V through the first-stage op-amp AD6045. The specific conversion circuit is shown below:

.. image:: images/24_media/image6.png
      
The -1V~+1V voltage from the first-stage op-amp is then transformed to a higher amplitude voltage signal through the second-stage op-amp. The amplitude of this op-amp can be adjusted using the adjustable resistor on the board. Through the second-stage op-amp, the analog signal output range can reach up to -5V~+5V.

.. image:: images/24_media/image7.png
      
The following table shows the correspondence between digital input signals and the output voltages after each op-amp stage:

+--------------------+--------------------+--------------------+--------------------+
| **DAC              | **AD9767           | **First-stage      | **Second-stage     |
| Data Input Value** | Current Output**   | Op-amp Output**    | Op-amp Output**    |
+====================+====================+====================+====================+
| 3fff               | +20mA              | -1V                | +5V                |
| (14-bit all high)  |                    |                    |                    |
+--------------------+--------------------+--------------------+--------------------+
| 0 (14-bit all low) | -20mA              | +1V                | -5V                |
+--------------------+--------------------+--------------------+--------------------+
| 2000 (mid value)   | 0mA                | 0V                 | 0V                 |
+--------------------+--------------------+--------------------+--------------------+

Digital Interface
~~~~~~~~~~~~~~~~~~

The digital interface of the AD9767 chip can be configured as Dual-port mode or Interleaved mode through the chip's mode pin (MODE). In the AN9767 module design, the AD9767 chip operates in Dual-port mode, where the dual-channel DA digital input interfaces are independent and separate. The data timing diagram for Dual-port mode is shown below:

.. image:: images/24_media/image8.png
      
The DA data is input to the AD9767 chip for DA conversion on the rising edges of the clock CLK and write signal WRT.

Program Design
--------------

The example provides a DA test program for the AN9767 module, which implements sine wave signal output through the AN9767 module.

The sine wave test program reads sine wave data stored in a ROM inside the FPGA, then outputs the sine wave data to the AN9767 module for digital-to-analog conversion, thereby generating the analog sine wave signal. The schematic diagram of the sine wave test program is shown below:

Dual-Channel Sine Wave Generation Program
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code:: verilog

 `timescale 1ns / 1ps
 //////////////////////////////////////////////////////////////////////////////////
 //Two sine wave outputs -10V ~ +10V
 //////////////////////////////////////////////////////////////////////////////////
 module ad9767_test
 (
 input sys_clk,                //  input clock  50Mhz
 
 output da1_clk,             //AD9767 CH1 clock
 output da1_wrt,             //AD9767 CH1 enable
 output [13:0] da1_data,     //AD9767 CH1 data output
 
 output da2_clk,             //AD9767 CH2 clock
 output da2_wrt,             //AD9767 CH2 enable
 output [13:0] da2_data      //AD9767 CH2 data output
 
 );
 
 reg [9:0] rom_addr;
 
 wire [13:0] rom_data;
 wire clk_125M;
 
 
 assign da1_clk=clk_125M;
 assign da1_wrt=clk_125M;
 assign da1_data=rom_data;
 
 assign da2_clk=clk_125M;
 assign da2_wrt=clk_125M;
 assign da2_data=rom_data;
 
 
 //DA output sin waveform
 always @(negedge clk_125M)
 begin
  rom_addr <= rom_addr + 1'b1 ;              //The output sine wave frequency is 122Khz
  // rom_addr <= rom_addr + 4 ;              //The output sine wave frequency is 488Khz
  // rom_addr <= rom_addr + 128 ;            //The output sine wave frequency is 15.6Mhz                             
 end 
 
 
 
 ROM ROM_inst
 (
 .clka(clk_125M), // input clka
 .addra(rom_addr), // input [8 : 0] addra
 .douta(rom_data) // output [7 : 0] douta
 );
 
 
 PLL PLL_inst
 (// Clock in ports
 .clk_in1    (sys_clk        ),      // IN
 // Clock out ports
 .clk_out1   (               ),      // OUT
 .clk_out2   (clk_125M       ),     // OUT
 // Status and control signals
 .reset      (1'b0           ),      // IN
 .locked     (               )
 );      
 
 endmodule


The program uses a PLL IP to generate a 125M DA output clock, then cyclically reads 1024 data points stored in ROM, and simultaneously outputs them to the DA data lines of both Channel 1 and Channel 2. The program can output sine waves of different frequencies by incrementing the address by 1, 4, or 128.
