AD9238 Dual-Channel Waveform Display Experiment
=================================================

**The Vivado project for this experiment is "ad9238_hdmi_test".**

Hardware Introduction
---------------------

Dual-Channel AD Module Description
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The ALINX high-speed AD module AN9238 is a 2-channel 65MSPS, 12-bit analog-to-digital conversion module. The module uses the AD9238 chip from ADI for AD conversion.
The AD9238 chip supports 2-channel AD input conversion, so one AD9238 chip supports a total of 2 AD input channels. The analog signal input supports single-ended analog signal input with an input voltage range of -5V to +5V, using SMA connectors.

The module has a standard 2.54mm pitch 40-pin female header for connecting to the FPGA development board.
The AN9238 module photo is shown below:

.. image:: images/22_media/image1.png
      
AN9238 module photo

**Parameter Description**

The following are the detailed parameters of the AN9238 high-speed AD module:

-  AD conversion chip: 1x AD9238

-  AD conversion channels: 2 channels;

-  AD sampling rate: 65MSPS;

-  AD sampling data width: 12 bits;

-  Digital interface level standard: +3.3V CMOS level

-  AD analog signal input range: -5V to +5V;

-  Analog signal input interface: SMA interface;

-  Measurement accuracy: approximately 10mV;

-  Operating temperature: -40° to 85°;

Module Function Description
~~~~~~~~~~~~~~~~~~~~~~~~~~~

The schematic block diagram of the AN9238 module is shown below:

.. image:: images/22_media/image2.png

For the detailed reference design of the AD9238 circuit, please refer to the AD9238 chip datasheet.

1) Single-ended input and op-amp circuit

The single-ended inputs AD1 and AD2 are fed through the J5 or J6 SMA connectors, with an input voltage range of -5V to +5V.

The on-board AD8065 op-amp chip and voltage divider resistors scale the -5V to +5V input voltage down to -1V to +1V. If users want to input a wider voltage range, they only need to modify the front-end voltage divider resistor values.

.. image:: images/22_media/image3.png
      
The following table shows the voltage comparison between the analog input signal and the AD8065 op-amp output:

+--------------------------------+-------------------------------------+
| **AD Analog Input Value**      | **AD8065 Op-amp Output**            |
+================================+=====================================+
| -5V                            | -1V                                 |
+--------------------------------+-------------------------------------+
| 0V                             | 0V                                  |
+--------------------------------+-------------------------------------+
| +5V                            | +1V                                 |
+--------------------------------+-------------------------------------+

2) Single-ended to differential conversion and AD conversion

The -1V to +1V input voltage is converted to a differential signal (VIN+ - VIN-) through the AD8138 chip. The common-mode level of the differential signal is determined by the CML pin of the AD.

.. image:: images/22_media/image4.png
      
The following table shows the voltage comparison from analog input signal to AD8138 differential output:

+----------------+------------------------+----------------------------+
| **AD Analog    | **AD8065 Op-amp        | **AD8138 Differential      |
| Input Value**  | Output**               | Output**\ (VIN+ - VIN-)   |
+================+========================+============================+
| -5V            | -1V                    | -1V                        |
+----------------+------------------------+----------------------------+
| 0V             | 0V                     | 0V                         |
+----------------+------------------------+----------------------------+
| +5V            | +1V                    | :sub:`+`\ 1V               |
+----------------+------------------------+----------------------------+

3) AD9238 Conversion

By default, the AD is configured in offset binary mode. The AD conversion values are shown in the figure below:

.. image:: images/22_media/image5.png
      
In the module circuit design, the VREF value of the AD9238 is 1V. The final analog signal input and AD conversion data are as follows:

+------------+-------------------+--------------------+---------------+
| **AD       | **AD8055 Op-amp** | **AD8138           | **AD9238      |
| Analog     |                   | Differential       | Digital       |
| Input      | **Output**        | Output**           | Output**      |
| Value**    |                   | (VIN+ - VIN-)      |               |
+============+===================+====================+===============+
| -5V        | -1V               | -1V                | 000000000000  |
+------------+-------------------+--------------------+---------------+
| 0V         | 0V                | 0V                 | 100000000000  |
+------------+-------------------+--------------------+---------------+
| +5V        | +1V               | +1V                | 11111111111   |
+------------+-------------------+--------------------+---------------+

From the table, we can see that when the input is -5V, the AD9238 digital conversion value is at its minimum, and when the input is +5V, the AD9238 digital conversion value is at its maximum.

4) AD9238 Digital Output Timing

The digital output of the AD9238 dual-channel AD is in +3.3V CMOS output mode, with 2 channels (A and B) having independent data and clock signals. The AD data is converted on the rising and falling edges of the clock, and the FPGA can sample the AD data using the AD clock.

Program Design
--------------

The display portion of this experiment is based on the previous HDMI color bar display experiment, with grid lines and waveforms overlaid on the color bars.
The block diagram of the entire project is shown below:

.. image:: images/22_media/image7.png

The ad9238_sample module mainly completes the single-channel data conversion of the AN9238. Only the upper 8 bits of the final data are used, converting the data width to 8 bits (for compatibility with other 8-bit AD module programs). Additionally, 1280 data samples are collected each time, then after waiting for a period, the next 1280 data samples are collected.

The wav_display module mainly completes the overlay display of waveform data. The module contains a dual-port RAM, where the write port is written by the ADC acquisition module, and the read port is used by the display module. When the grid display area is active, each display line reads the AD data values stored in RAM and compares them with the Y coordinate to determine whether to display the waveform or not.

Experimental Results
--------------------

Connect the circuit as shown below. Adjust the frequency and amplitude of the signal generator. The AN9238 input range is -5V to 5V. For easier observation of waveform data, the recommended signal input frequency is 200KHz to 1MHz. Observe the display output: the red waveform is the CH1 input, blue is the CH2 input. On the yellow grid, the top horizontal line represents 5V, the bottom horizontal line represents -5V, the middle horizontal line represents 0V, and each vertical line interval represents 10 sampling points.
